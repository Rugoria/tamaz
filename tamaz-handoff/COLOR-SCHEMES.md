# tamaz color schemes

Every scheme uses the same 12 tokens, so switching schemes never needs component changes.

| Token | Used for |
|---|---|
| `--bg` | page background |
| `--surface` | cards, form |
| `--surface-2` | tinted panels, icon tiles |
| `--ink` | main text |
| `--muted` | secondary text |
| `--line` | borders, dividers |
| `--accent` | primary buttons, highlighted headline word, promo panels |
| `--accent-ink` | text on accent buttons |
| `--aqua` | secondary color: eyebrows, pills, sliders, scan dots |
| `--aqua-soft` | secondary tint backgrounds |
| `--deep` | dark sections: marquee, journey timeline, cost result, scan card |
| `--deep-ink` | text on dark sections |
